Explanation of Bisection Method

The Bisection Method is a numerical method to find the root of a function by repeatedly halving an interval $[a, b]$. It works as follows:

  • Find $ x_m = \frac{a + b}{2} $, the midpoint of the interval.
  • Evaluate $ f(x_m) $.
  • If $ f(x_m) $ is very close to zero, we have found the root.
  • If $ f(x_m) $ has the same sign as $ f(a) $, update $ a = x_m $, else update $ b = x_m $.
  • Repeat until the error is below the tolerance limit.

Python Implementation of Bisection Method

The Bisection Method is implemented in Python using the following steps: 

def bisection_method(f, a, b, epsilon=0.001, max_iterations=100):
    """Performs the Bisection method to find a root of f(x)."""
    steps = []
    
    if f(a) * f(b) > 0:
        return None, "Invalid interval: f(a) and f(b) must have opposite signs."

    for iteration in range(max_iterations):
        mid = (a + b) / 2
        f_mid = f(mid)
        error_val = abs(b - a) / 2

        steps.append({
            "iteration": iteration + 1,
            "a": a,
            "b": b,
            "mid": mid,
            "f_mid": f_mid,
            "error": error_val
        })

        if abs(f_mid) < epsilon or error_val < epsilon:
            return steps, None

        if f_mid * f(a) < 0:
            b = mid
        else:
            a = mid

    return None, "Bisection method did not converge after 100 iterations."

The key steps in the Python function:

  • Step 1: Define the function and interval $[a, b]$.
  • Step 2: Check if $ f(a) \cdot f(b) < 0 $, ensuring a root exists.
  • Step 3: Compute the midpoint $ x_m = \frac{a + b}{2} $.
  • Step 4: Evaluate $ f(x_m) $.
  • Step 5: If $ f(x_m) $ is close to zero, return the result.
  • Step 6: Otherwise, update the interval:
    • If $ f(x_m) $ has the same sign as $ f(a) $, set $ a = x_m $.
    • Otherwise, set $ b = x_m $.
  • Step 7: Repeat until the error is below the threshold.
